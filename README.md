# Connections Game

An AI-powered word connections game built with **Next.js 15**, **Tailwind CSS**, **Claude AI** (for puzzle generation), and **Supabase** (for the leaderboard).

Every puzzle is freshly generated by Claude — no two games are the same.

---

## How to Play

1. You're shown **16 words**. They belong to **4 secret groups** of 4.
2. Select 4 words you think share a connection, then hit **Submit**.
3. You have **4 mistakes** before the game ends.
4. Categories range from Easy → Medium → Hard → Tricky.
5. Your score = groups solved × 100 + mistakes remaining × 25.

---

## Setup

### 1. Supabase — create the leaderboard table

In your Supabase project → **SQL Editor**, run:

```sql
create table connections_leaderboard (
  id          bigserial primary key,
  player_name text not null,
  score       integer not null,
  mistakes    integer not null,
  created_at  timestamptz default now()
);

alter table connections_leaderboard enable row level security;

create policy "Public read" on connections_leaderboard
  for select using (true);

create policy "Public insert" on connections_leaderboard
  for insert with check (true);
```

### 2. Environment Variables

In Vercel → **Settings → Environment Variables**, add these three:

| Variable | Where to find it |
|---|---|
| `ANTHROPIC_API_KEY` | [console.anthropic.com](https://console.anthropic.com) → API Keys |
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase → Settings → API → Project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase → Settings → API → anon public |

### 3. Deploy

Push to GitHub → import in Vercel → add env vars → Deploy.
